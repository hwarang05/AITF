# AITF

> AI Technology Framework

## 프로젝트 소개

AITF는 Synology NAS 기반의 문서를 AI(RAG)를 이용하여
권한을 유지한 상태에서 검색하고 질의응답을 제공하는
Enterprise Knowledge Platform이다.

본 프로젝트는 개인 프로젝트로 시작하지만,
향후 사내 서비스로 확장 가능한 구조를 목표로 한다.

---

## 목표

- Synology NAS 연동
- 권한 기반 문서 검색
- RAG 기반 AI 질의응답
- Local LLM(Ollama)
- Docker 기반 운영
- 모듈화된 구조
